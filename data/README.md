# Project Data

CITYMEMORY uses structured infrastructure records to build historical memory and support preventive decisions.

## Prototype Data

The current prototype uses seeded demonstration data and does not depend on live municipal systems.

## Planned Data Structure

- Assets
- Incidents
- Inspections
- Interventions
- Outcomes
- Context

## Production Data

Production deployment would use authorized municipal datasets through CSV uploads, APIs or database integrations.

## Data Privacy

Sensitive personal or citizen information should be minimized, protected and processed according to applicable data-governance requirements.
