# 3. Key Features

CITYMEMORY is built around six core capabilities that transform historical infrastructure records into reusable decision evidence.

The capabilities work together rather than operating as isolated modules.

---

## 3.1 Feature Overview

| Feature | Purpose |
|---|---|
| Infrastructure Memory | Maintains the historical timeline of an infrastructure asset |
| Intervention Survival + Infrastructure Amnesia | Measures observed intervention durability and highlights repeated short-lived repair cycles |
| Failure Echo Mapper | Identifies historical spatial-temporal relationships between failures |
| Failure Signature Engine | Identifies recurring contextual patterns associated with failures |
| Historical Intervention Comparison | Compares observed outcomes of historically comparable interventions |
| Memory-Weighted Preventive Action Planner | Uses historical intelligence to prioritize preventive actions |

The overall intelligence flow is:

**Remember → Analyze → Learn → Decide → Remember Again**

---

# 3.2 Infrastructure Memory

## Purpose

Infrastructure Memory creates a structured historical record for each infrastructure asset or location.

Instead of storing failures and repairs as disconnected events, CITYMEMORY links them to the corresponding asset and its historical context.

## Information Captured

Depending on data availability, the memory can contain:

- Asset identification
- Asset type
- Geographic location
- Failure or incident history
- Inspection records
- Previous interventions
- Observed outcomes
- Intervention dates
- Recurrence information
- Environmental or contextual information
